# Tuxchii 🐧

**Lichii + Fritchii + Linux Tweaks = Tuxchii.**

Tuxchii is [Frizti's Fritchii](https://github.com/Frizti/Fritchii) (the Lichii fork tuned for Ocarina of Time) built as a Linux AppImage, with a few extra tweaks so it feels at home on Linux:

- **NVIDIA DLSS on Linux.** One button (Settings → Graphics → Install DLSS) fetches NVIDIA's DLSS files onto your PC, then DLSS works like it does on Windows.
- **Smooth from the first launch.** New games offer to pre-build all their shaders.
- **Prepare Shaders on AMD, Intel and the Steam Deck**, not just NVIDIA.
- **Classic interface by default**, steamos big picture mode compatibility, it follows your desktop theme, fonts and scaling. Fritchii's own look is one checkbox away.
- **Always up to date.** Every new Fritchii release is built automatically on GitHub.

👉 **[Download the latest AppImage](../../releases/latest)**

Unofficial build. Report Linux problems here, not upstream. Games, keys and firmware are not included. Thanks to Frizti, zortos293 and the Lichii, Eden and yuzu contributors.
